# Product Decision Rule

For every proposed Hired AI capability:

1. Identify the user's desired outcome.
2. Identify the smallest action that materially improves that outcome.
3. Prefer lower-friction execution when expected value is comparable.
4. Preserve user authority, evidence truth, legal/professional gates and verified delivery.
5. Measure the user outcome that should teach the system whether the intervention worked.
6. Use technical superiority to improve user value, reliability, speed, trust, personalization, economic upside or defensibility.
7. Do not prioritize a feature because it is sophisticated, benchmarkable or easy to compare with another company.
8. Competitive research is internal product intelligence unless the founder explicitly requests a public comparison surface.

Canonical product sequence:

`desired outcome → highest-value intervention → superior implementation → low-friction execution → verified outcome → learning → better next intervention`
