# Hired-AI — Portfolio Proof Contract

**Track:** Agent system / commercial candidate

Hired-AI is complete only when its governed multi-agent pipeline performs real job-acquisition workflows reliably, preserves evidence, respects authorization, and improves measurable outcomes without unsafe automation.

Required proof: end-to-end state transitions; tests for agent boundaries, evidence, approvals, deduplication, retries, and resumability; adversarial tests for hallucinated jobs/contacts, bad evidence, application duplication, provider failure, and governance bypass; benchmarks for qualified-opportunity precision, workflow completion, time saved, cost, and recovery; security/privacy; production deployment; real-user usage and outcome metrics where commercialized.

**Next proof target:** run a fixed, audited job-search/application cohort through the pipeline and compare precision, completion, human intervention, errors, and outcomes against a manual/baseline workflow.
